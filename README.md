# NEW HEROES MOD

------------------------------------------------------------------------------------------------

## Download the Mod Manager

**Manual Install:**

1. Go to the [Mod Manager GitHub Page](https://github.com/DippityDapper/lokr-mod-manager "Mod Manager GitHub Page
    (https://github.com/DippityDapper/lokr-mod-manager)")
2. Click on the green `<> Code` dropdown button and `Download ZIP`

**QUICK INSTALL [https://github.com/DippityDapper/lokr-mod-manager/zipball/master](https://github.com/DippityDapper/lokr-mod-manager/zipball/master "https://github.com/DippityDapper/lokr-mod-manager/zipball/master")** ------------------------------------------------

## Unzip the Mod Manager folder

**

1. Go to the Downloads folder

****

1. Right click on the downloaded ZIP file; press `Extract All...` then `Extract`

****

1. Open the extracted folder and navigate through the folders until you find one labeled `lokr-mod-manager`

****

1. Click into the folder and open the `lokr-mod-manager.exe`

**------------------------------------------------

## Installing the Mod through the Mod Manager

**

1. Click the `Mod Download` button and `Install`

****

1. Once the loading bar says "Finished!" you may close the Manager and play!

****

1. Have fun!

**------------------------------------------------

## Updating the Mod

When updates are pushed, we will notify the server in ⁠change-log, and you must reopen the Mod Manager and click `Reinstall` in the Mod Download menu. ------------------------------------------------------------------------------------------------

- _If you'd like to uninstall the mod, the Mod Manager can do that for you, or you can reverify your game files in Steam._
- _This installer has NOT been tailored for MAC, and they are not applicable to mobile._
- _This should not corrupt any save files, but if they do, please ask for help!_
